# Security Policy

## Reporting a vulnerability

Contact [@dropafile](https://github.com/dropafile) or use GitHub Security Advisories.

## Scope

This policy covers the **dropafile/.github** meta-repository (org profile, governance docs, GitHub automation).

For vulnerabilities in the **dropafile** application, report via [dropafile/SECURITY.md](https://github.com/dropafile/dropafile/blob/main/SECURITY.md).
